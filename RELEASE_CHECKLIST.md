# Release Checklist

Use this checklist before every production release.

---

# Code Quality

* [ ] Working tree is clean.
* [ ] All changes committed.
* [ ] Latest branch pushed.
* [ ] Documentation updated.

---

# Runtime

* [ ] Application starts successfully.
* [ ] Configuration validation passes.
* [ ] Startup diagnostics displayed.
* [ ] Runtime heartbeat verified.
* [ ] Clean shutdown verified.

---

# Backtesting

* [ ] Backtest completes successfully.
* [ ] Performance report generated.
* [ ] Analytics verified.

---

# Paper Trading

* [ ] 100 completed paper trades.
* [ ] CSV reviewed.
* [ ] Exit reasons verified.
* [ ] Trade durations reviewed.
* [ ] Profit statistics reviewed.

---

# Risk Management

* [ ] Position sizing verified.
* [ ] Break-even verified.
* [ ] Trailing stop verified.
* [ ] Partial profit taking verified.
* [ ] Time exit verified.

---

# Regression

* [ ] No unexpected behavioural changes.
* [ ] Previous functionality preserved.
* [ ] Console output reviewed.

---

# Git

* [ ] Version committed.
* [ ] Version tagged.
* [ ] GitHub repository updated.

---

# Release Candidate

* [ ] Ready for Sprint 12.
* [ ] Trading logic frozen.
* [ ] Live deployment approved.
